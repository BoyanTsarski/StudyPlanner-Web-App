-Описание: Уеб приложение за ученици и студенти за организиране на задачи, изпити и проекти, проследяване на напредъка и планиране на учебния процес.

-Основни функции: създаване/редактиране/изтриване на задачи, приоритети, подзадачи, календар, dashboard, филтри, напомняния, статистики и Pomodoro таймер.

-Потребители: регистрирани (пълен достъп) и гости (ограничен достъп).

-Инструменти: ASP.NET Core (C#), SQL Server/, HTMLCSS,  Visual Studio/VS Code, Git/GitHub.
